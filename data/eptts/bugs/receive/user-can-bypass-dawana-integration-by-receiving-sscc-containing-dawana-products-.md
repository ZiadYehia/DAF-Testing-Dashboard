The user is able to bypass the Dawana integration by entering the SSCC number that contains Dawana products and receiving it through the Agent. 
   
--- 
**Steps to Reproduce:**
1. The user has a Dawana product that needs to be received through the Agent.
2. The user enters the SSCC number that contains the Dawana product into the Agent.
3. The user receives the product through the Agent.
   
--- 
**Expected Result:**
The Agent should prevent the user from receiving the Dawana product if it is not properly integrated with Dawana.
   
--- 
**Actual Result:**
The user is able to receive the Dawana product through the Agent without proper integration.
