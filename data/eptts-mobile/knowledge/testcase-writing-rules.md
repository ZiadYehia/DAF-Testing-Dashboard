# EPTTS Mobile — Test Case Writing Rules

> Adapt these rules as you learn more about the app's conventions.

- Test IDs follow the pattern `EPTTS-M-<FEATURE>-TC-<NNN>` (e.g., `EPTTS-M-LOGIN-TC-001`).
- All test cases must specify the device platform (Android / iOS / Both).
- GS1 scan steps should note whether a physical scanner or the camera is used.
- Offline / online state must be explicitly stated for sync-related test cases.
- Each test case covers exactly one user action or validation point.
